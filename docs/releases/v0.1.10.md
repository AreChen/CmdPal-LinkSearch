# LinkSearch 0.1.10

## What's Changed

- Improve OpenAI decision ranking with Score-based relevance and the search query in each question. Existing provider settings are preserved.
- Add a connection test for each ranking service, a configurable candidate limit, and visible errors without switching providers. Saving and testing keeps the settings page open.
- Show the original search results while ranking runs, cancel obsolete requests when the query changes, and keep the default selection at the top when the results are reordered.
- Omit empty descriptions and tags from ranking requests to reduce unnecessary input.
- Update the [English](https://github.com/AreChen/CmdPal-LinkSearch/blob/v0.1.10/docs/ranking.md) and [Chinese](https://github.com/AreChen/CmdPal-LinkSearch/blob/v0.1.10/docs/ranking.zh.md) guides with Score requests, configuration migration, privacy, and candidate limits.
- Update x64 and ARM64 MSIX packages to version `0.1.10.0`.

## Install

- Recommended: [Microsoft Store](https://apps.microsoft.com/detail/9MZ9Q4CFP2N9). Store updates become available after Microsoft certification and publication.
- Requires Microsoft PowerToys with Command Palette support.
- For manual sideloading, download the attached ZIP, extract it, and run `Add-AppDevPackage.ps1` from the folder matching your CPU architecture.
- GitHub sideload packages use a temporary self-signed certificate generated during packaging. The ZIP includes the certificate and installation script; a SHA-256 checksum is attached separately.

## 更新内容

- 优化 OpenAI 决策排序，使用 Score 相关性评分并在每个问题中包含搜索词，同时保留已有服务配置。
- 为各排序服务增加连接测试、可配置的候选数量上限和可见的错误提示；保存并测试时会保留设置页面。
- 排序期间先显示原始搜索结果，搜索词变化时取消过期请求，并在结果重新排序后保持顶部默认选中。
- 排序请求不再包含空的描述和标签，减少不必要的输入。
- 更新[中文](https://github.com/AreChen/CmdPal-LinkSearch/blob/v0.1.10/docs/ranking.zh.md)和[英文](https://github.com/AreChen/CmdPal-LinkSearch/blob/v0.1.10/docs/ranking.md)指南，说明 Score 请求、配置迁移、隐私和候选数量上限。
- x64 和 ARM64 MSIX 安装包版本更新为 `0.1.10.0`。

推荐通过 Microsoft Store 安装。商店更新需经微软认证和发布后才会提供，与 GitHub 发版时间独立。
