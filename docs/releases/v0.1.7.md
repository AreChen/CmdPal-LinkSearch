# LinkSearch 0.1.7

## What's Changed

- Choose between the existing Rerank API and System One decision-model ranking using Noul or Choice.
- Configure the decision service independently from the existing rerank service. Failed or invalid decision responses leave the original search order intact.
- Ranking requests send the search query and candidate titles, descriptions, and tags, without separate URL or collection fields.
- Update development and test dependencies and use the dedicated MSIX build tooling package.
- Update x64 and ARM64 MSIX packages to version `0.1.7.0`.

## Install

- Recommended: [Microsoft Store](https://apps.microsoft.com/detail/9MZ9Q4CFP2N9). Store updates become available after Microsoft certification and publication.
- Requires Microsoft PowerToys with Command Palette support.
- For manual sideloading, download the attached ZIP, extract it, and run `Add-AppDevPackage.ps1` from the folder matching your CPU architecture.
- GitHub sideload packages use a temporary self-signed certificate generated during packaging. The ZIP includes the certificate and installation script; a SHA-256 checksum is attached separately.

## 更新内容

- 支持在现有 Rerank API 和 System One 决策模型的 Noul、Choice 排序方式之间选择。
- 决策服务与原有 Rerank 服务分别配置；请求失败或响应无效时保留原始搜索顺序。
- 排序请求仅发送搜索词以及候选的标题、描述和标签，不单独发送链接地址或收藏夹字段。
- 更新开发和测试依赖，并使用独立的 MSIX 构建工具包。
- x64 和 ARM64 MSIX 安装包版本更新为 `0.1.7.0`。

推荐通过 Microsoft Store 安装。商店更新需经微软认证和发布后才会提供，与 GitHub 发版时间独立。
