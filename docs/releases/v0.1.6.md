# LinkSearch 0.1.6

## What's Changed

- Updated the Command Palette SDK from `0.11.260520004` to `0.12.260812002` for compatibility with the current extension toolkit.
- Updated the Microsoft Store MSIX package version to `0.1.6.0` for x64 and ARM64.
- GitHub releases now load versioned release notes from the repository.

Search, Linkwarden settings, optional semantic reranking, and Chinese/English interface support remain available.

## Install

- Recommended: [Microsoft Store](https://apps.microsoft.com/detail/9MZ9Q4CFP2N9). Store updates become available separately after Microsoft certification and publication.
- Requires Microsoft PowerToys with Command Palette support.
- For manual sideloading, download the attached ZIP, extract it, and run `Add-AppDevPackage.ps1` from the folder matching your CPU architecture.
- GitHub sideload packages use a temporary self-signed certificate generated during packaging. The ZIP includes the certificate and installation script; a SHA-256 checksum is attached separately.

## 更新内容

- Command Palette SDK 从 `0.11.260520004` 升级至 `0.12.260812002`。
- x64 和 ARM64 商店安装包版本更新为 `0.1.6.0`。
- GitHub 发版改为读取仓库内对应版本的更新日志。

推荐通过 Microsoft Store 安装。商店更新需经微软认证和发布后才会提供，与 GitHub 发版时间独立。
