# LinkSearch 0.1.9

## What's Changed

- Add OpenAI Decisions and OpenRouter Decisions alongside custom System One, with separate endpoints, API keys, and models for each provider. Compatible gateways are supported.
- Simplify ranking settings: hide them when disabled, switch modes and providers in one click, and link to official setup guides. API keys are masked in the settings UI.
- Preserve the original order if a decision provider refuses a question or returns an incomplete or invalid response.
- Move ranking setup and API examples into dedicated [English](https://github.com/AreChen/CmdPal-LinkSearch/blob/v0.1.9/docs/ranking.md) and [Chinese](https://github.com/AreChen/CmdPal-LinkSearch/blob/v0.1.9/docs/ranking.zh.md) guides.
- Update x64 and ARM64 MSIX packages to version `0.1.9.0`.

## Install

- Recommended: [Microsoft Store](https://apps.microsoft.com/detail/9MZ9Q4CFP2N9). Store updates become available after Microsoft certification and publication.
- Requires Microsoft PowerToys with Command Palette support.
- For manual sideloading, download the attached ZIP, extract it, and run `Add-AppDevPackage.ps1` from the folder matching your CPU architecture.
- GitHub sideload packages use a temporary self-signed certificate generated during packaging. The ZIP includes the certificate and installation script; a SHA-256 checksum is attached separately.

## 更新内容

- 在自建 System One 之外新增 OpenAI Decisions 和 OpenRouter Decisions，各服务的接口地址、API 密钥和模型独立配置，支持兼容网关。
- 简化重排序设置：关闭时隐藏配置，一键切换模式和服务，并提供官方配置指南入口；设置界面会遮挡 API 密钥。
- 决策服务拒答或返回不完整、无效的响应时，保留原始搜索顺序。
- 将排序配置和 API 示例拆分为独立的[中文](https://github.com/AreChen/CmdPal-LinkSearch/blob/v0.1.9/docs/ranking.zh.md)和[英文](https://github.com/AreChen/CmdPal-LinkSearch/blob/v0.1.9/docs/ranking.md)指南。
- x64 和 ARM64 MSIX 安装包版本更新为 `0.1.9.0`。

推荐通过 Microsoft Store 安装。商店更新需经微软认证和发布后才会提供，与 GitHub 发版时间独立。
